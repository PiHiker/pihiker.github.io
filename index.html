Field note 01 · Bitcoin networking

What happens when Tor goes offline?

A peer-to-peer mining node needs to find other nodes. My experimental work on P2Poolv2 asks whether it can learn onion addresses from its peers without advertising an IP address.

The failure case

If a node is configured to use only Tor, losing the proxy should mean losing its peers until Tor returns. Quietly switching to a direct connection would defeat the operator’s choice.

Status: local experimental patches for upstream P2Poolv2.
