Privacy, security, and Bitcoin.

In penetration testing, one of my first questions is “What can someone on the other side of this connection learn?” My Bitcoin projects explore that question from three places: a miner connecting to a pool, a developer paying for an API call, and a wallet owner working locally.

01 / Mining software · Alpha

ArkPool Gateway

Connect a miner to ArkPool over Tor. The gateway carries mining traffic; the pool handles payouts over Ark. Wallet keys stay out of the gateway.

With native Stratum V2 (SV2), a compatible miner authenticates the pool over its Tor onion service. ArkPool may have been the first Bitcoin mining pool to offer this combination, though that distinction is unconfirmed.

03 / Local tool · Python

Bech32PassHunter

A wallet can open with a different BIP39 passphrase and show a different set of addresses. This tool checks for a match against the first BIP84 receiving address, without looking up a balance.

The public demo needs no wallet secrets. For personal use, the mnemonic prompt hides your input and a match stays hidden by default.

ArkPool / Reading pool stats

Why can share counts rise while hashrate stays flat?

Shares can have different difficulty. The share chart counts each accepted event once; the hashrate chart weights verified work by difficulty. On the ArkPool dashboard, use hashrate to compare work over time and the snapshot timestamp to see how fresh the numbers are.

Bech32PassHunter / 21 November 2026

Can a wallet tool stay offline while the computer stays online?

A successful offline demo tells me the tool doesn’t need the internet. It doesn’t tell me what happens when something tries to connect. I wanted to check both.

I ran the public wallet demo through the Linux launcher. It found the expected match. In a separate check under the same launcher, only the loopback interface was visible and an outbound connection failed. When I simulated a failure to create that isolation, the launcher stopped instead of starting the tool with normal network access.

You can try the demo with ./offline.sh --demo after installation. The launcher blocks network access for the tool and its workers. It doesn’t protect against someone recording your terminal. Offline setup instructions

Field note / Experimental P2Poolv2 work

What should a node do when Tor goes offline?

In onion-only mode, losing connectivity is the right outcome. A direct connection might keep shares flowing, but it would expose the network address the operator chose to keep private.

My experimental patches for P2Poolv2 address two separate questions: how to keep peer connections on Tor, and how to discover another peer by its onion address.

What I observed

When I stopped Tor, the node lost its peers. That alone didn’t tell me whether it had tried another route, so I checked the traffic capture for direct fallback connections. I saw none during the outage. When Tor returned, the node connected to peers again.
